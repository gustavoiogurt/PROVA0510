# Frequência

Portal de vendas de notícias fictício desenvolvido para a prova de Desenvolvimento Web 2.

## Proposta

O projeto foi criado com tema próprio sobre música, cultura, tecnologia e agenda cultural. A ideia foi aproveitar a organização de um portal jornalístico (como o da referência), mas construir uma identidade visual diferente da tela-modelo.

## Tecnologias

- HTML5 semântico
- CSS3
- JavaScript puro
- Google Fonts

## Paleta

- Fundo: #FBFAF8
- Superfície: #FFFFFF
- Texto: #17151C
- Texto secundário: #68636F
- Roxo principal: #6B45D8
- Rosa: #D94F88
- Verde: #268A73
- Laranja: #C47A26
- Linha: #E4E0E7

As cores são declaradas como variáveis CSS para facilitar manutenção e a criação do tema escuro.

## Fontes

DM Serif Display: usada no logotipo e nos títulos.
Inter: usada na navegação, textos, metadados e botões.
As duas fontes são carregadas pelo Google Fonts.

## Imagens

As imagens das matérias são arquivos SVG criados para o próprio projeto. Elas não dependem de banco de imagens externo. Cada `<img>` possui atributo `alt` descritivo, conforme a exigência de acessibilidade da atividade.

## Recursos em JavaScript

1. Relógio com atualização a cada segundo.
2. Filtro de notícias por categoria.
3. Busca de notícias pelo título.
4. Botão "Carregar mais".
5. Alternância entre tema claro e escuro.
6. Persistência do tema com `localStorage`.
7. Validação do formulário de newsletter.

O JavaScript usa apenas recursos nativos do navegador, sem frameworks ou bibliotecas externas.
